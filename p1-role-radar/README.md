# Como executar O RolêRadar

1. Clone este repositório com o comando: git clone https://github.com/WallaceeS/p1-pdm

2. Acesse a pasta do projeto:
    cd p1-pdm/p1-role-radar

3. Instale as dependências necessárias com o comando: npm install

4. No arquivo src/utils/chaves.js preencha as chaves com suas próprias chaves de API
   GEOAPIFY_KEY: Crie uma conta no site: https://myprojects.geoapify.com/register para obter sua chave API
   PRIMEUI_LICENSE: Crie uma conta no site: https://primeui.store/signin para obter sua chave API

5. Inicie a aplicação com o comando: npm run dev

6.  No navegador digite localhost:5173 ou clique no link que surgiu no seu terminal
    Permita acesso a localização para conseguir usar o programa.
